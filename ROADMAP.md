# Планы

Сейчас у агента есть `hosts`, `list`, `start`, `stop`, `key` и `paste`.
Кандидат в 0.2.0: пункты 1–2 и 4–6.

## Исправления

1. **`networkAddress` для каждого хоста.** Сейчас адрес один на все хосты,
   поэтому «LAN / VPN» не показывает два хоста сразу (например, Windows и
   Linux).
2. **Причина `startFailed`.** CLI и панель не говорят, почему эмулятор упал;
   причина (например, нет доступа к `/dev/kvm`) есть только в
   `host-data/logs/emulator-<avd>.log`. Показывать хвост лога в ошибке.
3. **Проверить режим «сеть BB»** (`bb connect`) на хосте Windows и Linux.

## Глаза и руки агента

4. **`screenshot`.** Снимок экрана вложением, чтобы агент видел результат.
5. **`tap`, `swipe`, `text`.** Агент сам проходит сценарии в приложении.
6. **`logcat`.** Логи с фильтром по пакету и уровню, чтобы видеть краши.
7. **`install <apk>` и `open <url>`.** Установка сборки и deep link одной
   командой; в панели — перетаскивание APK.

## Панель

8. Поворот экрана, холодная загрузка, сброс данных, снапшоты AVD.
9. Запись экрана в GIF или MP4 для PR и отчётов.
10. Предупреждение о нехватке памяти на хосте.

## Охват

11. Хосты macOS: эмулятор на Apple Silicon с arm64-образами.
12. Создание AVD из плагина. Сейчас плагин ничего не ставит — это смена
    позиции.
13. Физические устройства по adb, только по явному включению.
